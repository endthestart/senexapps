Poundlock Toolkit

Find out what works on your hardware.

Toolkit inspects a machine, shows you the setup and a bounded test plan, runs it when you say so, and compares the configurations it tested.

Install from PyPI Read the Guide

Python 3.11 or later on Linux and macOS. Source on GitHub.

Inspect, plan, test, compare. A command that finishes, with nothing left running.

  • Inspect

    Reads the hardware of the local machine or an SSH target. Inspecting calls no model and no paid API.

  • Review the plan

    Every setup command and resource bound is shown before anything runs. Nothing executes until you say so.

  • Compare what was tested

    Reports compare only the configurations that actually ran, and recommend from them.

  • Qualification

    Export the result as a qualification file and validate it, to keep with the configuration you deploy.

  • Tool-call checks

    Measures how well a model's tool calls follow a nested JSON Schema, locally or over SSH.

  • Installs nothing for you

    No model weights, drivers or services are installed automatically. Model servers stay yours to set up.

Try it offline. No model, Docker or credentials.

python3 -m venv .venv
.venv/bin/python -m pip install poundlock-toolkit
.venv/bin/poundlock-toolkit inspect

Then run a synthetic report from start to finish:

source .venv/bin/activate
poundlock-toolkit example openai --output openai.json
poundlock-toolkit demo openai.json --output demo.json
poundlock-toolkit recommend demo.json --output report.md

A synthetic report shows how Toolkit works. Only a live run says anything about your hardware or a model.
