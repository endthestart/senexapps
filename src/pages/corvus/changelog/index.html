SENEX Corvus

Release notes

Newest first. Releases before the SENEX name shipped as Andermic Photo Importer.

0.2.0-alpha.1 · Source preview

5 November 2026

The first release as SENEX Corvus. It is still source only: build it on Apple silicon or Intel; there is no prebuilt or notarized download.

  • A new name and bundle ID, so macOS treats Corvus as a new app. It adopts Andermic Photo Importer's settings once; the README explains the move.
  • The SENEX look shared with Pictor: dark appearance, star-blue accent, status badges and a constellation icon.
  • Starts in the menu bar, with an optional window at launch. Closing the window keeps work running.
  • USB camera import through Image Capture, with originals staged and verified.
  • Faster repeat scans from a 30-day verification cache; imports still verify every file in full.
  • Select All, Select All New and Deselect All, and bounded memory use.
  • Bundled ExifTool updated to 13.60.

Checked with 261 synthetic safety checks and builds on both architectures. Real cameras, physical card reinsertion, VoiceOver and clean-machine installs are not yet qualified.

0.1.0-alpha.2 · Source preview

5 October 2026

The first public, MIT-licensed source preview. Build it on Apple silicon or Intel; there is no prebuilt or notarized download.

  • Thumbnail grid with new photos selected, date and type filters, and Import Selected or Import All New.
  • Destination, date and event folder templates, and saved presets.
  • Card detection and folder sources; scanning previews without copying.
  • RAW, JPEG and sidecar grouping, duplicates confirmed by content, verified copies, safe name clashes, interruption reports and retry.
  • A built-in metadata reader with no separate installation.
  • Optional hand-off to your editor and card ejection after a verified import.

Checked with 118 synthetic safety tests on both architectures. Real cameras, older macOS versions, clean-machine installs and signed builds are not yet qualified.
