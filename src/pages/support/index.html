Support

Help for each app, and how to report a problem.

Corvus

  • Read the guide: building, installing, updating, folder structures and every setting.
  • Report a problem or ask a question on GitHub. Say which macOS version and camera you use.
  • Corvus needs macOS 13 or later. Cameras that appear only in Image Capture must first be copied into a normal folder.
  • This is a source preview: real-camera, older-macOS and clean-machine checks are still in progress.

Pictor

Pictor is in development and has no public build or issue tracker yet. Its support details appear here with the first release.
