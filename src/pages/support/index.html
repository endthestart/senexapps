Support

Help for each app, and how to report a problem.

Corvus

  • Read the guide: building, installing, updating, folder structures and every setting.
  • Report a problem or ask a question on GitHub. Say which macOS version and camera you use.
  • Corvus needs macOS 13 or later. Since 0.2.0-alpha.1 it also imports from USB cameras through Image Capture.
  • This is a source preview: real-camera, older-macOS and clean-machine checks are still in progress.

Pictor

  • Read the guide: the preview's limits, building from source and the commands.
  • Report a problem or ask a question on GitHub. Say which macOS version and camera you use.
  • Pictor needs macOS 12 or later, lens data from darktable or Homebrew's lensfun, and RAW files from a Nikon Z6 II or D700.
  • This is a preview and isn't notarized, so macOS blocks the first open. Try to open it, then choose Open Anyway in System Settings > Privacy & Security.
