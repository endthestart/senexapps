0.1.0-alpha.2 · Source preview

5 October 2026

The first public, MIT-licensed source preview. Build it on Apple silicon or Intel; there is no prebuilt or notarized download.

  • Thumbnail grid with new photos selected, date and type filters, and Import Selected or Import All New.
  • Destination, date and event folder templates, and saved presets.
  • Card detection and folder sources; scanning previews without copying.
  • RAW, JPEG and sidecar grouping, duplicates confirmed by content, verified copies, safe name clashes, interruption reports and retry.
  • A built-in metadata reader with no separate installation.
  • Optional hand-off to your editor and card ejection after a verified import.

Checked with 118 synthetic safety tests on both architectures. Real cameras, older macOS versions, clean-machine installs and signed builds are not yet qualified.
