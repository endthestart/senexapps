SENEX Corvus · The Crow

Only the new photos, straight from the card.

Corvus is a small menu-bar app that copies new photo and video originals from a camera card or folder into ordinary folders, and checks every copy. No account, no cloud service, no photo library database.

Build from Source Release Notes

Source preview 0.1.0-alpha.2, released as Andermic Photo Importer. macOS 13 or later, Apple silicon or Intel.

From card to folders. Nothing is copied until you say so.

  • Insert a card

    Corvus notices the card and scans it in the background. Scanning only previews; nothing is copied until you click Import.

  • New photos come selected

    Click to include or exclude, Shift-click for a range, filter by date or file type, or hide what is already imported. RAW, JPEG and sidecar files stay together.

  • Your folders

    Year / Month / Day by default, or your own template from {YYYY}, {MM}, {DD} and {event}. Each photo goes to its own capture day; a missing date is never guessed.

  • Copied, then checked

    Every copy is verified. Duplicates are confirmed by content, name clashes are handled safely, and an interrupted import says what happened and can be retried.

  • On to your editor

    Optionally open the new folders in your photo editor and eject the card once the import is verified.

  • Out of the way

    Corvus lives in the menu bar. Close the window and scans and imports keep running; ⌘O opens a folder instead of a card.

Build it yourself. There is no signed download yet.

You need macOS 13 or later and Apple's Command Line Tools; no Xcode project or paid Apple membership. The first build takes about two minutes.

xcode-select --install
git clone https://github.com/endthestart/andermic-photo-importer.git
cd andermic-photo-importer
./build.sh

The app appears in dist/. The README covers installing, updating and every setting.

The code on GitHub still has the old name and look, Andermic Photo Importer. The screenshots here show the current development build.
