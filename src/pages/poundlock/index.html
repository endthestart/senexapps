Poundlock · The lock that lifts the boat

Put your own model servers to work.

Poundlock gives the model servers on your own machines one OpenAI-compatible endpoint, and runs coding jobs that come back as a patch with independently checked results.

Get the Latest Release Getting Started

The server runs on Linux x86_64 with Docker. Source on GitHub.

One API for your models. You choose what may leave your network.

  • One endpoint

    Connect llama.cpp, Ollama, vLLM or any OpenAI-compatible server. Each application gets its own token and permissions, and requests for a busy model wait in a queue.

  • Durable coding jobs

    Submit a prompt and source files. An agent works in a restricted container, and the job survives a disconnection. You get a patch and the results of your own checks.

  • Explicit external access

    Local inference is separate from permission to send data to an outside model. One weekly and monthly budget covers external spend across every application and job.

  • Wake and release

    Enrol Linux or macOS machines as nodes, wake them with Wake-on-LAN where supported, and load and unload Ollama models automatically.

  • Hands for any agent

    poundlock mcp lets an MCP client plan and review while every line of code comes from a durable job.

  • Yours to run

    You choose the model and its settings. Model servers, GPU drivers and model downloads stay under your control.

The family. Test the hardware, serve the models, do the work.

  • Poundlock Toolkit

    Finds which models, runtimes and settings work on a machine before you rely on it.

  • Poundlock Dispatch

    A desktop app and terminal client that plan, delegate and review coding work through Poundlock.

  • Documentation

    Guides for all three, and how they fit together.
