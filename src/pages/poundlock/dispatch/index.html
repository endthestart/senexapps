Poundlock Dispatch

A project manager for your own models.

Dispatch is a desktop app and a terminal client. You agree a plan with a manager, it hands tasks to workers that edit your project folder, and checks and review decide what is accepted.

Get the Latest Release Read the Guide Developer preview

For Apple silicon Macs. Needs a Poundlock controller and an application token. Source on GitHub.

Plan, delegate, review. The code runs on your machine.

  • A manager that can't write code

    The manager plans, delegates and reviews. Workers write the code, with inference served by your Poundlock controller.

  • Permission modes

    Ask for approval, Approve for me, or Full access. A model outside your network always asks separately.

  • Nothing committed for you

    Dispatch doesn't commit or push. Accepted work stays in your project folder for you to review.

  • Attached work

    The default. Work runs in your project folder and stops when you close Dispatch; reopening restores the conversation and plan.

  • Autopilot

    A preview. Builds an approved plan unattended, in a container on a dedicated VM, in a private copy of the project.

  • Desktop and terminal

    The same work from the app or from dispatch in a terminal, which needs Node.js 22.19.0 or later.

Details. Private by design.
